# GhostDesk Portal

Веб-приложение для регистрации, авторизации и управления токеном доступа GhostDesk. Интерфейс повторяет визуальный стиль основного лендинга и включает страницы регистрации, входа и личного кабинета.

## Возможности

- Регистрация пользователей с email, паролем, подтверждением пароля и необязательным реферальным кодом.
- Автоматическая генерация уникального токена доступа, установка тарифа `free` и хранение реферального кода.
- Безопасное хэширование паролей с помощью `bcrypt` и хранение данных в SQLite.
- Авторизация с использованием сессий Express и защищённых cookie.
- Личный кабинет с отображением тарифа, токена и управляющими действиями.
- UI, вдохновлённый лендингом GhostDesk: тёмная тема, акцентные цвета и плавные градиенты.

## Требования

- Node.js 18+

## Быстрый старт

```bash
npm install
npm run dev
```

Приложение запустится на `http://localhost:3000`.

Для production-запуска используйте:

```bash
npm run start
```

## Структура проекта

- `src/server.js` — конфигурация Express, маршруты и middleware.
- `src/db.js` — подключение к SQLite и миграция таблицы пользователей.
- `views/` — шаблоны EJS для страниц портала.
- `public/` — статические ресурсы (CSS и JS).
- `data/ghostdesk.db` — файл базы данных (создаётся автоматически).

## Переменные окружения

- `PORT` — порт для сервера (по умолчанию `3000`).
- `SESSION_SECRET` — секрет для подписания cookie сессии. Задайте собственное значение в production.

## Безопасность

- Пароли пользователей никогда не сохраняются в открытом виде.
- Сессии конфигурированы с безопасными настройками cookie.
- Включён Helmet для современных HTTP-заголовков защиты.
